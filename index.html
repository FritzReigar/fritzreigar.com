Proyectos

Producto propio · En el mercado

Snugport

Centro de operaciones para freelancers: tracker de horas con tarifa, proyectos, pipeline de clientes, vencimientos y checklists operativos, en una sola página que funciona sin instalación y sin conexión. Escrito entero en JavaScript vanilla: cero dependencias, sin bundler ni transpilación, ~28.800 líneas propias y 13 secciones de producto (v2.26). PWA instalable con service worker propio.

La sincronización opcional entre dispositivos va sobre Supabase (Postgres, Auth y Edge Functions) hablando con su API REST sin cliente oficial, y el muro de suscripción —mensual o anual, cobrada por Stripe con webhook propio— vive en las políticas RLS de la base de datos, no en el navegador: decide el servidor. El corte está puesto en la escritura, nunca en la lectura, para no retener los datos de nadie. Round-trip Mac ↔ Windows validado en vivo. Las cuatro Edge Functions son ~800 líneas de TypeScript sobre Deno; el webhook de Stripe verifica la firma con HMAC-SHA256 y Web Crypto, sin el SDK de Stripe.

JavaScript vanilla · TypeScript (Deno) · Supabase · Postgres RLS · Stripe · PWA · Cloudflare Pages
